# اتصال به نرم‌افزار «کیف پول»

مخزن کیف پول: https://github.com/AmirMazinani561/Arena_Wallet

---

## چطور کار می‌کند

```
  کیف پول                          حساب سرمایه‌گذاران
 ┌──────────────┐                 ┌──────────────────┐
 │ ثبت تراکنش   │                 │                  │
 │      ↓       │   POST          │  وضعیت: pending  │
 │ یک طرف شریک؟ │ ──────────────► │  بدون قیمت       │
 │      ↓ بله   │  /api/          │  خارج از محاسبات │
 │ ارسال        │  wallet-intake  │        ↓         │
 └──────────────┘                 │  کاربر قیمت      │
                                  │  شمش را می‌زند    │
                                  │        ↓         │
                                  │  confirmed       │
                                  │  وارد محاسبات    │
                                  └──────────────────┘
```

**نکتهٔ کلیدی:** تا وقتی قیمت وارد نشود، تراکنش در وزن، درصد سهم،
ارزش روز و سود/زیان **هیچ اثری ندارد**.

---

## تصمیم‌های قطعی‌شده

| موضوع | تصمیم |
|---|---|
| واحد پول | **ریال** در هر دو — بدون تبدیل |
| کدام حساب‌ها | فقط آن‌هایی که در `WALLET_PARTNER_MAP` نام برده‌اید |
| کارمزد بانکی | **نادیده** گرفته می‌شود |
| انتقال بین دو شریک | منتقل **نمی‌شود** (خنثی از نظر سرمایهٔ کل) |

---

## نگاشت فیلدها

| کیف پول | این‌جا | توضیح |
|---|---|---|
| `amount` | `amount_rial` | بدون تبدیل |
| `shamsiDate` `"1404/6/2"` | `jdate` `"14040602"` | خودکار |
| `description` | `description` | عیناً |
| `toAccountId` = شریک | `kind = 'IN'` | پول به شریک رفت |
| `fromAccountId` = شریک | `kind = 'OUT'` | پول از شریک آمد |
| `id` | `source_id` | ضد تکرار |

## راه‌اندازی

### گام ۱ — شرکا را بسازید
در نرم‌افزار سرمایه‌گذاری، بخش «شرکا»، هر شریک را اضافه کنید.
سپس شناسهٔ هرکدام را بردارید:

```js
// در کنسول مرورگر (F12)
partners.map(p => `${p.name}: ${p.id}`).join('\n')
```

### گام ۲ — شناسهٔ حساب‌های کیف پول
در کیف پول، صفحهٔ حساب‌ها را باز کنید و شناسهٔ حساب هر شریک
(نوع `person`) را بردارید.

### گام ۳ — نگاشت
در متغیرهای محیطی نرم‌افزار سرمایه‌گذاری:

```
WALLET_INTAKE_TOKEN=یک-رشتهٔ-تصادفی-طولانی
WALLET_PARTNER_MAP={"acc_ali":"uuid-علی","acc_reza":"uuid-رضا"}
```

تولید توکن:
```bash
openssl rand -hex 24
```

### گام ۴ — سمت کیف پول
پوشهٔ [`wallet-patch/`](../wallet-patch/) را ببینید. سه کار کوچک:
افزودن یک فایل، یک خط فراخوانی، و دو متغیر محیطی.

### گام ۵ — تست
```bash
curl -H "x-intake-token: توکن-شما" \
     https://آدرس-شما/api/wallet-intake
```

پاسخ درست:
```json
{"ok":true,"mappedAccounts":2}
```

---

## پاسخ‌های اندپوینت

| وضعیت | پاسخ |
|---|---|
| ساخته شد | `{"created":"...","kind":"IN","partner_id":"..."}` |
| هیچ طرفی شریک نیست | `{"skipped":"no-partner"}` |
| هر دو طرف شریک | `{"skipped":"internal-transfer"}` |
| تکراری | `{"skipped":"duplicate","id":"..."}` |
| توکن غلط | `401` |

---

## حریم خصوصی

اندپوینت **فقط** تراکنش‌هایی را می‌پذیرد که یک طرفشان دقیقاً در
`WALLET_PARTNER_MAP` باشد. تراکنش‌های شخصی شما (خرید، قبض، حقوق…)
هرگز منتقل نمی‌شوند و حتی اگر ارسال شوند، با `no-partner` رد می‌گردند.

---

## آزمون‌های انجام‌شده

این سناریوها روی **هر دو دیتابیس** PostgreSQL و MySQL آزموده شده‌اند:

- ✅ پول به شریک → `IN`
- ✅ پول از شریک → `OUT`
- ✅ ارسال دوباره با همان شناسه → رد می‌شود
- ✅ تراکنش خصوصی → رد می‌شود
- ✅ انتقال بین دو شریک → رد می‌شود
- ✅ بدون توکن → `401`
- ✅ تاریخ `1404/6/10` و `1404/06/10` هر دو درست تبدیل می‌شوند
- ✅ تراکنش pending وزن کل را تغییر نمی‌دهد
- ✅ بعد از قیمت‌گذاری وارد محاسبات می‌شود
