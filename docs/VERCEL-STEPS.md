# راه‌اندازی روی Vercel — گام به گام

هر گام را که تمام کردید، تیک بزنید. کل کار حدود ۱۵ دقیقه است.

---

## گام ۰ — سه کلید که همین حالا لازم دارید

اینها را جایی یادداشت کنید (Notepad یا هرجا). بعداً استفاده می‌شوند:

```
AUTH_SECRET=4411c690443ce4bc8181d33e90f1765049edf5d77c06e23e1b2d4746bb94c11a

WALLET_INTAKE_TOKEN=ac1ce1ce7b9abc97c3b9cca317f172179655900c6b8f3a2e

ADMIN_PASSWORD=  ← یک رمز قوی که خودتان انتخاب می‌کنید
```

> این دو کلید بالا مخصوص شما تولید شده‌اند و تصادفی‌اند. لازم نیست
> حفظشان کنید، فقط جایی نگهشان دارید.

---

## گام ۱ — گرفتن آدرس دیتابیس از Supabase

۱. وارد [supabase.com](https://supabase.com) شوید و پروژه‌تان را باز کنید.
۲. از منوی چپ: **Project Settings** (چرخ‌دنده پایین) ← **Database**
۳. پایین صفحه بخش **Connection string** را پیدا کنید.
۴. تب **URI** را انتخاب کنید.
۵. از منوی کشویی بالای آن، **Session pooler** را انتخاب نمایید.

آدرسی شبیه این می‌بینید:

```
postgresql://postgres.abcdefgh:[YOUR-PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:5432/postgres
```

۶. `[YOUR-PASSWORD]` را با رمز دیتابیس‌تان جایگزین کنید.

> ⚠️ **مهم:** حتماً **Session pooler** یا **Transaction pooler** را بگیرید،
> نه **Direct connection**. روی Vercel اتصال مستقیم پایدار نیست.

> اگر رمز دیتابیس را یادتان نیست: در همان صفحه **Reset database password**.

این آدرس کامل را کنار آن سه کلید یادداشت کنید.

## گام ۲ — فرستادن کد به گیت‌هاب

در پوشهٔ پروژه:

```bash
git init
git add -A
git commit -m "نسخهٔ ۲ — بک‌اند مستقل و اتصال کیف پول"
git branch -M main
git remote add origin https://github.com/AmirMazinani561/نام-مخزن.git
git push -u origin main
```

> اگر مخزن از قبل دارید و می‌خواهید جایگزین شود:
> `git push -u origin main --force`

**بررسی:** در گیت‌هاب باید پوشه‌های `src`، `public` و `wallet-patch` را ببینید.
فایل `.env.local` **نباید** آنجا باشد (رمزها در آن است و عمداً نادیده گرفته شده).

---

## گام ۳ — ساخت پروژه در Vercel

۱. به [vercel.com/new](https://vercel.com/new) بروید.
۲. مخزن را از فهرست انتخاب و **Import** کنید.
۳. تنظیمات را **دست نزنید** — Vercel خودش Next.js را می‌شناسد.
۴. **هنوز Deploy نزنید.** اول گام ۴.

---

## گام ۴ — وارد کردن متغیرها

در همان صفحه، بخش **Environment Variables** را باز کنید و این پنج مورد را
یکی‌یکی اضافه نمایید:

| Name | Value |
|---|---|
| `DATABASE_URL` | آدرسی که در گام ۱ گرفتید |
| `AUTH_SECRET` | کلید اول از گام ۰ |
| `ADMIN_USERNAME` | `admin` |
| `ADMIN_PASSWORD` | رمزی که خودتان انتخاب کردید |
| `WALLET_INTAKE_TOKEN` | کلید دوم از گام ۰ |

> هر پنج مورد باید برای هر سه محیط (Production، Preview، Development)
> فعال باشند — معمولاً پیش‌فرض همین است.

حالا **Deploy** را بزنید و منتظر بمانید (حدود ۲ دقیقه).

## گام ۵ — بررسی سلامت

بعد از اتمام، این آدرس را باز کنید:

```
https://نام-پروژه.vercel.app/api/health
```

### پاسخ درست:

```json
{
  "ok": true,
  "database": "connected",
  "dialect": "pg",
  "tablesReady": true,
  "authSecret": true
}
```

🎉 اگر این را دیدید، **جدول‌ها خودکار ساخته شده‌اند**. هیچ SQL دستی لازم نیست.

### اگر خطا دیدید:

| پیام | معنی و راه‌حل |
|---|---|
| `"database":"unset"` | `DATABASE_URL` وارد نشده |
| `"authSecret":false` | `AUTH_SECRET` وارد نشده |
| `اتصال به دیتابیس برقرار نشد` | آدرس غلط است، یا Direct گرفته‌اید به جای Pooler |
| `نام کاربری یا رمز دیتابیس نادرست` | رمز داخل آدرس اشتباه است |
| `password authentication failed` | همان بالا — `[YOUR-PASSWORD]` را جایگزین نکرده‌اید |

بعد از هر اصلاح متغیر، در Vercel باید **Redeploy** بزنید
(تب Deployments ← سه‌نقطه ← Redeploy).

## گام ۶ — اولین ورود

آدرس اصلی را باز کنید:

```
https://نام-پروژه.vercel.app
```

- نام کاربری: `admin`
- رمز: همان `ADMIN_PASSWORD`

> کاربر مدیر **فقط در اولین ورود** از روی متغیر محیطی ساخته می‌شود.
> بعد از آن در دیتابیس ذخیره است و تغییر متغیر اثری ندارد.

## گام ۷ — ساخت شرکا و گرفتن شناسه‌ها

۱. وارد بخش **شرکا** شوید و هر شریک را اضافه کنید.
۲. کلید `F12` را بزنید تا ابزار توسعه‌دهنده باز شود.
۳. تب **Console** را انتخاب کنید.
۴. این را بچسبانید و Enter بزنید:

```js
copy(partners.map(p => p.name + " → " + p.id).join("\n"))
```

حالا فهرست در کلیپ‌بورد شماست. جایی بچسبانید:

```
علی → 3f2a1b8c-...
رضا → 9d4e7c2a-...
```

---

## گام ۸ — اتصال کیف پول (اختیاری، بعداً هم می‌شود)

۱. در کیف پول، شناسهٔ حساب هر شریک (نوع `person`) را پیدا کنید.
۲. نگاشت را بسازید:

```json
{"شناسه-حساب-علی":"3f2a1b8c-...","شناسه-حساب-رضا":"9d4e7c2a-..."}
```

۳. در Vercel این متغیر را اضافه کنید:

```
WALLET_PARTNER_MAP={"acc_ali":"3f2a1b8c-...","acc_reza":"9d4e7c2a-..."}
```

۴. **Redeploy** بزنید.
۵. تست کنید:

```bash
curl -H "x-intake-token: ac1ce1ce7b9abc97c3b9cca317f172179655900c6b8f3a2e" \
     https://نام-پروژه.vercel.app/api/wallet-intake
```

پاسخ درست: `{"ok":true,"mappedAccounts":2}`

۶. حالا سراغ پوشهٔ `wallet-patch/` بروید و سه کار کوچک آنجا را
   در مخزن کیف پول انجام دهید.

---

## اگر چیزی خراب شد

در Vercel: تب **Deployments** ← روی آخرین استقرار کلیک ← **Runtime Logs**.
پیام خطای دقیق آنجاست و معمولاً فارسی و قابل فهم است.
