# حساب سرمایه‌گذاران

نرم‌افزار مدیریت سرمایهٔ شرکا در صنعت آلومینیوم.
هر ورود و خروج پول در همان لحظه با قیمت شمش به **وزن** تبدیل می‌شود؛
درصد سهم هر شریک از روی وزن او محاسبه می‌گردد، نه از روی مبلغ ریالی.

```
وزن = مبلغ ریالی ÷ قیمت هر کیلوگرم       (ورود مثبت، خروج منفی)
سهم = وزن شریک ÷ وزن کل
```

با تغییر قیمت، **وزن ثابت می‌ماند** و فقط ارزش ریالی تغییر می‌کند.

## نسخهٔ ۲ — چه چیزی عوض شد؟

نسخهٔ قبلی یک فایل HTML بود که مستقیم از مرورگر به Supabase وصل می‌شد.
حالا یک برنامهٔ **Next.js با بک‌اند واقعی** است:

| | نسخهٔ ۱ | نسخهٔ ۲ |
|---|---|---|
| دیتابیس | فقط Supabase | **MySQL، MariaDB، PostgreSQL** |
| احراز هویت | Supabase Auth | **جدول users خودمان + کوکی امضاشده** |
| کلید دیتابیس | داخل فایل، قابل دیدن | **فقط روی سرور** |
| اتصال کیف پول | نداشت | **اندپوینت اختصاصی** |
| هاست | فقط Vercel | **Vercel، دایرکت‌ادمین، VPS** |

نسخهٔ قدیمی در `legacy/standalone.html` نگه داشته شده است.

## راه‌اندازی سریع

```bash
npm install
cp .env.example .env      # مقادیر را پر کنید
npm run dev
```

سپس `http://localhost:3000` را باز کنید.

### حداقل تنظیمات لازم

```bash
DATABASE_URL=postgresql://...        # یا mysql://...
AUTH_SECRET=$(openssl rand -hex 32)  # حتماً تصادفی
ADMIN_USERNAME=admin
ADMIN_PASSWORD=یک-رمز-قوی
```

> 🎉 جدول‌ها در **اولین اجرا خودکار ساخته می‌شوند**. هیچ اسکریپت SQL
> دستی لازم نیست. همان کد روی MySQL و PostgreSQL کار می‌کند.

### بررسی سلامت

```
GET /api/health
```

```json
{"ok":true,"database":"connected","dialect":"pg","tablesReady":true}
```

## اتصال به کیف پول

تراکنش‌هایی که در «کیف پول» ثبت می‌شوند و یک طرفشان شریک است،
خودکار این‌جا با وضعیت **در انتظار قیمت** ساخته می‌شوند و تا وارد
کردن قیمت شمش، **در هیچ محاسبه‌ای شرکت نمی‌کنند**.

راهنمای کامل: [docs/WALLET-SYNC.md](docs/WALLET-SYNC.md)
کد آمادهٔ سمت کیف پول: [wallet-patch/](wallet-patch/)

## ساختار پروژه

```
src/
├── app/
│   ├── page.tsx           رابط کاربری
│   ├── _body.html         بدنهٔ HTML رابط
│   └── api/               اندپوینت‌ها
│       ├── auth/          ورود، خروج، کاربر فعلی
│       ├── partners/      شرکا
│       ├── transactions/  تراکنش‌ها
│       ├── settings/      قیمت جاری
│       ├── health/        بررسی سلامت
│       └── wallet-intake/ دریافت از کیف پول
├── db/
│   ├── client.ts          لایهٔ اتصال دوگانه MySQL/PostgreSQL
│   └── repo.ts            ساخت خودکار جداول و پرس‌وجوها
└── lib/
    ├── auth.ts            احراز هویت سمت سرور
    └── jdate.ts           تاریخ شمسی

public/
├── app.css                استایل + فونت وزیرمتن (جاسازی‌شده)
└── app.js                 منطق برنامه

wallet-patch/              وصلهٔ آمادهٔ مخزن کیف پول
legacy/standalone.html     نسخهٔ تک‌فایلی قدیمی
```
