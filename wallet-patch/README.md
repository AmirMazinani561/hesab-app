# وصل کردن کیف پول به نرم‌افزار سرمایه

هدف: وقتی در کیف پول پولی به حساب «سرمایه سلطانی» یا «سرمایه مزینانی»
وارد یا از آن خارج می‌شود، همان تراکنش خودش در نرم‌افزار سرمایه هم ساخته شود.

**فقط یک کار دارید:** سه تغییر کوچک در مخزن کیف پول. تمام.
نیازی به پیدا کردن شناسه، کپی کردن کد طولانی یا تنظیم نگاشت نیست —
نرم‌افزار خودش نام حساب را با نام شریک تطبیق می‌دهد.

---

## پیش‌نیاز (یک‌بار)

در نرم‌افزار سرمایه، صفحهٔ **شرکا**، دو شریک با نام فامیلی بسازید:
`سلطانی` و `مزینانی`.

همین کافی است. نرم‌افزار این نام‌ها را با حساب‌های کیف پول خودش جور می‌کند.
همهٔ این حالت‌ها شناخته می‌شوند:

| نام حساب در کیف پول | وصل می‌شود به |
|---|---|
| سرمایه سلطانی | سلطانی |
| آقای سلطانی | سلطانی |
| سرمایه گذاری مزینانی | مزینانی |
| حساب سرمایه مزینانی | مزینانی |
| سرمايه سلطاني (با ی عربی) | سلطانی |

## گام ۱ — کپی یک فایل

فایل `equity-sync.ts` (کنار همین راهنماست) را در مخزن کیف پول بگذارید در:

```
src/lib/equity-sync.ts
```

## گام ۲ — دو تکه در فایل تراکنش‌ها

فایل `src/app/api/transactions/route.ts` را در مخزن کیف پول باز کنید.

**الف)** بالای فایل، کنار بقیهٔ `import`ها این خط را اضافه کنید:

```ts
import { syncToEquity } from "@/lib/equity-sync";
```

**ب)** داخل تابع `POST`، دنبال جایی بگردید که تراکنش ساخته می‌شود:

```ts
const transaction = await createTransaction({
```

بعد از پایان آن دستور (بعد از `});`) این را اضافه کنید:

```ts
// همگام‌سازی با نرم‌افزار سرمایه
void syncToEquity(
  {
    id: transaction.id,
    amount: transaction.amount,
    fromAccountId: transaction.fromAccountId,
    toAccountId: transaction.toAccountId,
    shamsiDate: transaction.shamsiDate,
    description: transaction.description,
  },
  { from: fromAcc.name, to: toAcc.name }
);
```

## تست

این آدرس را در مرورگر باز کنید (به‌جای آدرس نمونه، آدرس خودتان):

```
https://آدرس-شما.vercel.app/api/wallet-intake
```

چون توکن لازم دارد، ساده‌تر است در ترمینال:

```bash
curl -H "x-intake-token: ac1ce1ce7b9abc97c3b9cca317f172179655900c6b8f3a2e" \
     https://آدرس-شما.vercel.app/api/wallet-intake
```

اگر `"ok": true` دید، همه‌چیز درست است.

می‌خواهید یک نام خاص را امتحان کنید؟

```bash
curl -G -H "x-intake-token: ..." https://آدرس-شما.vercel.app/api/wallet-intake \
     --data-urlencode "name=سرمایه سلطانی"
```

## چه چیزی منتقل می‌شود، چه چیزی نه

| حالت | نتیجه |
|---|---|
| بانک ← سرمایه سلطانی | تراکنش **آورده** ساخته می‌شود |
| سرمایه مزینانی ← صندوق | تراکنش **برداشت** ساخته می‌شود |
| بانک ← خرید خانه | منتقل **نمی‌شود** |
| سلطانی ← مزینانی | منتقل **نمی‌شود** (انتقال داخلی) |
| تراکنش تکراری | دوباره ساخته **نمی‌شود** |

تراکنش‌های شخصی شما هرگز به نرم‌افزار سرمایه نمی‌روند.

---

## بعدش چه می‌شود؟

تراکنش‌های واردشده با وضعیت **«در انتظار قیمت»** ثبت می‌شوند و تا وقتی
قیمت شمش آن روز را وارد نکنید، در هیچ محاسبه‌ای (وزن، درصد سهم، داشبورد)
تأثیر نمی‌گذارند. این عمدی است — چون وزن بدون قیمت معنا ندارد.

در نرم‌افزار سرمایه فهرست «در انتظار قیمت» را می‌بینید و برای هرکدام
قیمت را وارد می‌کنید.
